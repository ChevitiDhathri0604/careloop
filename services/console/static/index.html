    Formal architecture review mapping CareLoop's multi-agent clinical safety gate directly to Microsoft Azure Well-Architected Framework guidelines.

    1. Reliability (Score: 98/100)

    • Multi-Layer Guardrails: Regex + embedding prompt-injection filter blocks SMS exfiltration payloads.

    • Observability: OpenTelemetry W3C distributed tracing across all agents and API routes.
